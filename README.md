# Exvacorp Studios — GitHub Pages SEO

Sitio estático responsive con páginas independientes, blog, buscador interno, sitemap, robots, Open Graph y JSON-LD.

## Importante
- Reemplaza `https://exvacorp.github.io/` por tu dominio/URL real en `canonical`, `sitemap.xml` y JSON-LD si tu URL de GitHub Pages es distinta.
- Google Play no ofrece en una página estática un endpoint público oficial y estable para obtener contador exacto de descargas o filtrar reseñas dinámicamente. Por eso la web enlaza a la ficha oficial y no fabrica cifras/reseñas.
- Si después conectas un backend/API autorizado, el bloque de ExvaTitan está preparado para sustituirse por datos dinámicos.
- Envía `sitemap.xml` a Google Search Console y Bing Webmaster Tools.
