EXVACORP STUDIOS - GITHUB PAGES

IMPORTANTE:
1. Sube LOS ARCHIVOS Y CARPETAS que están dentro de este ZIP a la RAÍZ del repositorio exvatitan-privacy.
2. index.html debe quedar directamente en: /index.html (no dentro de otra carpeta).
3. styles.css debe quedar directamente en: /styles.css.
4. assets debe quedar en: /assets/.
5. Conserva .nojekyll y .github/.
6. En Settings > Pages usa la rama que contiene estos archivos y carpeta /(root).

Esta versión usa rutas relativas, igual que la versión original que sí funcionaba.
El JavaScript calcula automáticamente la ruta de data/playstore.json desde script.js, por lo que no depende del nombre del repositorio.
