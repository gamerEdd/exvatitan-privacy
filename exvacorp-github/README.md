# Exvacorp Studios — GitHub Pages

Sitio estático listo para GitHub Pages.

## Publicación
1. Sube el contenido de esta carpeta a la raíz del repositorio.
2. En GitHub: Settings → Pages.
3. En Build and deployment selecciona **Deploy from a branch**.
4. Selecciona `main` y `/ (root)` y guarda.

## Rutas
- `/` — web principal de Exvacorp Studios.
- `/privacy/` — política de privacidad de ExvaTitan.

## Nota sobre capturas
Las capturas de ExvaTitan se cargan desde los recursos públicos de la ficha oficial de Google Play. El banner y el logo de Exvacorp están incluidos localmente en `assets/`.
